논문 진행 단계별 발표 안내

발표는 연구노트의 논문 단계와 1:1로 갑니다. 발표 준비 = 해당 단계의 연구노트를 채우는 일입니다.

발표 회차 한눈에

회차 발표 주제 연구노트 단계 핵심 질문
1기획 방향기획무엇을, 왜, 어떤 데이터로 연구하는가
2관련연구·기법리서치남들은 어떻게 했고, 내 연구는 무엇이 다른가
3제안기법 설계관련기법어떤 모델·파이프라인으로, 어떻게 검증할 것인가
4실험 검토실험결과결과가 가설을 지지하는가, 기준선 대비 얼마나 좋은가
5정리 1논문작성논문 뼈대(절 구성·그림·표)가 섰는가
6정리 2 (최종)검토·투고완성 초고, 투고 대상, 남은 한계

매주 금요일 수업. 1그룹과 2그룹이 한 주씩 번갈아 발표하므로 한 회차가 2주에 걸칩니다. 회차별 날짜는 수업 시간에 안내합니다.

발표 형식 (모든 회차 공통)

  • 발표 5분 이내, 슬라이드 5장 이내. 발표 후 질의·피드백.
  • 5장 안에 연구질문 한 줄과 다음 회차까지 할 일·막힌 점은 꼭 들어가게 하세요. 지난 회차 피드백을 반영했으면 한 줄로 언급.
  • 발표 자료를 미리 제출할 필요는 없습니다. 다만 연구노트에 미리 올려두면 발표 전에 읽고 더 구체적인 피드백을 줄 수 있으니 가급적 올려주세요.
  • 발표 자료는 연구노트 기록에서 뽑아도 됩니다. AI에게 "이번 회차 발표용으로 지난 기록 보고서 뽑아줘" 라고 하세요.

회차별 준비 내용

1회차 · 기획 방향 (연구노트 단계: 기획)
발표에 담을 것
  • 연구질문 1~2개와 가설. "이 연구가 끝나면 무엇을 알게 되는가" 한 문장.
  • 왜 지금 이 문제인가 (실무·학술적 동기).
  • 확보했거나 확보 가능한 데이터 (출처·규모·접근 가능 여부).
  • 딥러닝이 들어갈 자리 (어떤 예측·분류·생성 문제로 바꿀 것인가).
  • 연구 범위와 하지 않을 것.
연구노트 준비물
  • 프로젝트 등록 (제목·요약·목표 저널 후보·태그)
  • 기획 단계 정리 작성: 연구질문·가설·기여점·범위
  • 기록 1건 이상 (데이터 탐색, 주제 후보 비교 등)
  • 다음 할 일 3개 이상 등록
2회차 · 관련연구·기법 (연구노트 단계: 리서치)
발표에 담을 것
  • 선행연구 10편 이상을 2~4개 흐름(클러스터)으로 묶어서 정리.
  • 각 흐름의 대표 논문: 문제 정의, 데이터, 기법, 결과, 한계.
  • 내 연구의 차별점: 기존 연구 중 어디에 붙고, 무엇이 비어 있는가.
  • 후보 기법 2~3개 비교표 (장단점, 데이터 요구량, 구현 난이도).
  • 1회차 피드백 반영 결과 (연구질문이 바뀌었으면 왜 바뀌었는지).
연구노트 준비물
  • 리서치 단계 정리: 문헌 지형도 + 차별점 (관련연구 절의 뼈대)
  • 문헌 정리 기록 (읽은 논문은 기록에 서지·요약·시사점 남기기)
  • 기획 단계가 바뀌었으면 기획 정리도 갱신
3회차 · 제안기법 설계 (연구노트 단계: 관련기법)
발표에 담을 것
  • 전체 파이프라인 그림 (입력 → 전처리 → 모델 → 출력 → 평가).
  • 제안 모델 구조와 선택 이유. 기존 기법 대비 무엇을 바꿨는가.
  • 실험 설계: 기준선(baseline) 2개 이상, 평가 지표, 데이터 분할(train/valid/test), 반복·시드.
  • 데이터 전처리 현황과 기술 통계 (크기, 분포, 결측, 라벨 불균형).
  • 예비 실험이 있으면 결과 1~2개 (없어도 됨, 대신 일정 제시).
연구노트 준비물
  • 관련기법 단계 정리: 모델·실험 설계 (방법 절의 뼈대)
  • 코드·환경 세팅 기록 (저장소 경로, 실행 명령, 환경)
  • 전처리 결과 기록 (수치 표 포함)
4회차 · 실험 검토 (연구노트 단계: 실험결과)
발표에 담을 것
  • 메인 결과표: 제안 기법 vs 기준선, 지표별, 반복 평균±표준편차.
  • 가설별 판정: 지지 / 부분 지지 / 기각, 근거 수치.
  • 절제 실험(ablation) 또는 민감도 분석 1개 이상.
  • 실패한 실험과 원인 가설. 무엇을 바꿔서 다시 돌렸는가.
  • 오류 분석: 모델이 틀리는 사례 유형.
연구노트 준비물
  • 실험결과 단계 정리: 결과 요약표 + 해석 (실험 절의 뼈대)
  • 실험 1회당 기록 1건 (설정·수치·결론). 실패도 기록.
  • 그림·표 파일명과 생성 스크립트를 기록에 남기기 (재현 가능하게)
5회차 · 정리 1 (연구노트 단계: 논문작성)
발표에 담을 것
  • 논문 목차와 각 절의 핵심 문장 (서론·관련연구·방법·실험·논의·결론).
  • 그림·표 최종본 후보 (논문에 실을 4~6개).
  • 초록 초안 (200~250단어).
  • 4회차 피드백으로 추가한 실험이 있으면 결과.
  • 목표 저널·학회 1순위와 그 이유 (분량·포맷·마감).
연구노트 준비물
  • 논문작성 단계 정리: 절별 뼈대와 진행률
  • 절 하나 쓸 때마다 기록 1건
  • 초고 파일 위치(Overleaf 링크 등)를 프로젝트 요약에 기재
6회차 · 정리 2 (최종 발표) (연구노트 단계: 검토·투고)
발표에 담을 것
  • 완성 초고 기준으로 학회 발표처럼 5분 안에 압축.
  • 기여점 3줄 요약, 핵심 결과 1장, 한계와 후속 연구.
  • 한 학기 동안 연구질문이 어떻게 바뀌었는지 (1회차 → 6회차).
  • 투고 계획: 대상 저널, 제출 예정일, 남은 작업.
연구노트 준비물
  • 검토·투고 단계 정리: 내부 검토 의견과 반영 내역
  • 완성 초고 파일 제출 (PDF) + 연구노트에 최종 기록
  • 전체 기간 보고서 출력해서 첨부 (AI에게 "학기 전체 보고서 뽑아줘")

평가 관점

매 회차 발표 후 연구노트에 피드백을 남깁니다. 다음 회차 발표에서 피드백을 어떻게 반영했는지 한 줄로 보여주세요. 연구노트의 "평가 답변"으로 반영 계획을 남겨도 됩니다.

관점 보는 것
문제 정의·기여연구질문이 분명한가, 기여점이 새로운가
방법 타당성기법 선택과 실험 설계가 질문에 맞는가
실험·근거결과가 충분하고 재현 가능한가, 해석이 타당한가
글쓰기·완성도구성·그림·표·문장
기록 충실도연구노트에 매주 진행이 남아 있는가, 피드백에 답했는가

회차마다 중심이 다릅니다. 1~2회차는 문제 정의, 3회차는 방법, 4회차는 실험, 5~6회차는 글쓰기를 주로 봅니다.
