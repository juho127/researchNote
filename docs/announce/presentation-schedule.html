논문 진행 단계별 발표 안내

발표는 연구노트의 논문 단계와 1:1로 갑니다. 딥러닝·예측 연구와 사회과학 방법론 연구 두 갈래로 준비 내용을 적었습니다.

발표는 연구노트의 논문 단계와 1:1로 갑니다. 발표 준비 = 해당 단계의 연구노트를 채우는 일입니다.

연구 유형에 따라 준비 내용이 조금 다릅니다. 각 회차에 두 갈래를 적어 두었으니 자기 연구에 맞는 쪽을 따르세요.

  • 🔷 딥러닝·예측 모델 연구: 데이터로 모델을 학습·평가하는 연구 (예측, 분류, 생성, 추천)
  • 🔶 사회과학 방법론 연구: 이론에서 가설을 끌어내 설문·실험·2차자료·인터뷰로 검증하는 연구 (조직, 마케팅, 소비자 행동 등). 딥러닝은 텍스트 분석·변수 생성·예측 등 일부 단계에 쓸 수 있습니다.

발표 회차 한눈에

회차발표 주제연구노트 단계핵심 질문
1기획 방향기획무엇을, 왜, 어떤 자료로 연구하는가
2관련연구·기법리서치남들은 어떻게 했고, 내 연구는 무엇이 다른가
3제안기법·연구설계관련기법어떤 모델(또는 연구모형)으로, 어떻게 검증할 것인가
4실험·분석 결과 검토실험결과결과가 가설을 지지하는가, 기준선(또는 대안 설명) 대비 얼마나 설득력 있는가
5정리 1논문작성논문 뼈대(절 구성·그림·표)가 섰는가
6정리 2 (최종)검토·투고완성 초고, 투고 대상, 남은 한계

매주 금요일 수업. 1그룹과 2그룹이 한 주씩 번갈아 발표하므로 한 회차가 2주에 걸칩니다. 회차별 날짜는 수업 시간에 안내합니다.

발표 형식 (모든 회차 공통)

  • 발표 5분 이내, 슬라이드 5장 이내. 발표 후 질의·피드백.
  • 5장 안에 연구질문 한 줄과 다음 회차까지 할 일·막힌 점은 꼭 들어가게 하세요. 지난 회차 피드백을 반영했으면 한 줄로 언급.
  • 발표 자료를 미리 제출할 필요는 없습니다. 다만 연구노트에 미리 올려두면 발표 전에 읽고 더 구체적인 피드백을 줄 수 있으니 가급적 올려주세요.
  • 발표 자료는 연구노트 기록에서 뽑아도 됩니다. AI에게 "이번 회차 발표용으로 지난 기록 보고서 뽑아줘" 라고 하세요.

회차별 준비 내용

1회차 · 기획 방향 (단계: 기획)

공통

  • 연구질문 1~2개. "이 연구가 끝나면 무엇을 알게 되는가" 한 문장.
  • 왜 지금 이 문제인가 (실무·학술적 동기).
  • 연구 범위와 하지 않을 것.

🔷 딥러닝·예측

  • 확보했거나 확보 가능한 데이터 (출처·규모·접근 가능 여부).
  • 딥러닝이 들어갈 자리 (어떤 예측·분류·생성 문제로 바꿀 것인가).

🔶 사회과학 방법론

  • 핵심 구성개념(변수) 후보: 독립·종속·매개/조절 변수를 말로 정의.
  • 분석 단위 (개인 / 팀 / 조직 / 국가)와 대상 모집단.
  • 자료 수집 방식 후보: 설문, 실험, 2차자료(패널·공시·리뷰 데이터), 인터뷰 중 무엇이 가능한가.
  • 딥러닝을 쓴다면 어디에 (예: 리뷰·공시 텍스트에서 변수 추출, 결과 예측).

연구노트 준비물

  • 프로젝트 등록 (제목·요약·목표 저널 후보·태그)
  • 기획 단계 정리 작성: 연구질문·가설(초안)·기여점·범위
  • 기록 1건 이상 (데이터 탐색, 주제 후보 비교 등)
  • 다음 할 일 3개 이상 등록

2회차 · 관련연구·기법 (단계: 리서치)

공통

  • 선행연구 10편 이상을 2~4개 흐름(클러스터)으로 묶어서 정리.
  • 각 흐름의 대표 논문: 문제 정의, 자료, 방법, 결과, 한계.
  • 내 연구의 차별점: 기존 연구 중 어디에 붙고, 무엇이 비어 있는가 (research gap).
  • 1회차 피드백 반영 결과 (연구질문이 바뀌었으면 왜 바뀌었는지).

🔷 딥러닝·예측

  • 후보 기법 2~3개 비교표 (장단점, 데이터 요구량, 구현 난이도).
  • 같은 과제의 벤치마크·공개 데이터셋과 보고된 성능.

🔶 사회과학 방법론

  • 이론적 배경 후보 1~2개 (예: SOR, 신호이론, 자원기반관점)와 왜 이 이론인가.
  • 선행연구가 쓴 측정 도구·척도와 출처 (그대로 쓸 것 / 수정할 것).
  • 가설 도출: H1, H2… 각 가설의 근거 논문.
  • 선행연구의 연구설계 유형 (횡단 설문 / 실험 / 패널 / 질적)과 한계.

연구노트 준비물

  • 리서치 단계 정리: 문헌 지형도 + 차별점 (관련연구 절의 뼈대)
  • 문헌 정리 기록 (읽은 논문은 기록에 서지·요약·시사점 남기기)
  • 기획 단계가 바뀌었으면 기획 정리도 갱신

3회차 · 제안기법·연구설계 (단계: 관련기법)

🔷 딥러닝·예측

  • 전체 파이프라인 그림 (입력 → 전처리 → 모델 → 출력 → 평가).
  • 제안 모델 구조와 선택 이유. 기존 기법 대비 무엇을 바꿨는가.
  • 실험 설계: 기준선(baseline) 2개 이상, 평가 지표, 데이터 분할(train/valid/test), 반복·시드.
  • 데이터 전처리 현황과 기술 통계 (크기, 분포, 결측, 라벨 불균형).
  • 예비 실험이 있으면 결과 1~2개 (없어도 됨, 대신 일정 제시).

🔶 사회과학 방법론

  • 연구모형 그림 (변수 간 화살표)과 가설 목록 최종본.
  • 조작화·측정: 변수별 척도(문항 수, 출처, 응답 형식), 조작 변수라면 조작 방법.
  • 연구설계: 설문(표본 프레임·목표 표본 수·표집 방법), 실험(요인 설계 예: 2×2, 무작위 배정, 조작 점검 문항), 2차자료(자료원·기간·식별 전략), 질적(인터뷰 대상·수·프로토콜).
  • 분석 방법: 회귀, SEM, PROCESS(매개·조절), 패널 고정효과, DID, 텍스트 분석 등. 왜 이 방법인가.
  • 표본 크기 근거(검정력 계산), 공통방법편의 대책, IRB·사전등록 여부.
  • 예비 조사(pilot)가 있으면 결과. 딥러닝을 쓰는 단계가 있으면 그 파이프라인.

연구노트 준비물

  • 관련기법 단계 정리: 모델·실험 설계 또는 연구모형·측정·분석 계획 (방법 절의 뼈대)
  • 코드·환경 세팅 기록 또는 설문지·실험 자극물 초안 (파일 위치)
  • 전처리 결과 또는 예비 조사 결과 기록 (수치 표 포함)

4회차 · 실험·분석 결과 검토 (단계: 실험결과)

🔷 딥러닝·예측

  • 메인 결과표: 제안 기법 vs 기준선, 지표별, 반복 평균±표준편차.
  • 가설별 판정: 지지 / 부분 지지 / 기각, 근거 수치.
  • 절제 실험(ablation) 또는 민감도 분석 1개 이상.
  • 실패한 실험과 원인 가설. 무엇을 바꿔서 다시 돌렸는가.
  • 오류 분석: 모델이 틀리는 사례 유형.

🔶 사회과학 방법론

  • 자료 수집 현황: 응답 수·응답률·불성실 응답 제거 기준, 실험이면 조작 점검 결과, 표본 특성표.
  • 측정 품질: 신뢰도(Cronbach α), 타당도(CFA 적합도, AVE·CR), 상관행렬.
  • 가설 검정 결과표: 계수·표준오차·p값(또는 신뢰구간), 가설별 지지 / 기각.
  • 매개·조절 효과 그림, 실험이면 조건별 평균 그래프.
  • 강건성 검사와 대안 설명 배제 (통제변수 추가, 다른 모형, 하위 표본).
  • 예상과 다른 결과와 그 해석 후보. 자료를 더 모아야 하면 계획.

연구노트 준비물

  • 실험결과 단계 정리: 결과 요약표 + 해석 (실험/결과 절의 뼈대)
  • 실험(또는 분석) 1회당 기록 1건 (설정·수치·결론). 실패도 기록.
  • 그림·표 파일명과 생성 스크립트(또는 SPSS/R 명령)를 기록에 남기기 (재현 가능하게)

5회차 · 정리 1 (단계: 논문작성)

공통

  • 논문 목차와 각 절의 핵심 문장 (서론·관련연구·방법·결과·논의·결론).
  • 그림·표 최종본 후보 (논문에 실을 4~6개).
  • 초록 초안 (200~250단어).
  • 4회차 피드백으로 추가한 실험·분석이 있으면 결과.
  • 목표 저널·학회 1순위와 그 이유 (분량·포맷·마감).

🔶 사회과학 방법론 추가

  • 논의 절 뼈대: 이론적 시사점(어떤 이론을 확장·반박하는가), 실무적 시사점, 한계(외적 타당성, 공통방법편의, 인과 추론 한계)와 후속 연구.

연구노트 준비물

  • 논문작성 단계 정리: 절별 뼈대와 진행률
  • 절 하나 쓸 때마다 기록 1건
  • 초고 파일 위치(Overleaf 링크 등)를 프로젝트 요약에 기재

6회차 · 정리 2 (최종 발표, 단계: 검토·투고)

공통

  • 완성 초고 기준으로 학회 발표처럼 5분 안에 압축.
  • 기여점 3줄 요약, 핵심 결과 1장, 한계와 후속 연구.
  • 한 학기 동안 연구질문이 어떻게 바뀌었는지 (1회차 → 6회차).
  • 투고 계획: 대상 저널, 제출 예정일, 남은 작업.

연구노트 준비물

  • 검토·투고 단계 정리: 내부 검토 의견과 반영 내역
  • 완성 초고 파일 제출 (PDF) + 연구노트에 최종 기록
  • 전체 기간 보고서 출력해서 첨부 (AI에게 "학기 전체 보고서 뽑아줘")

평가 관점

매 회차 발표 후 연구노트에 피드백을 남깁니다. 다음 회차 발표에서 피드백을 어떻게 반영했는지 한 줄로 보여주세요. 연구노트의 "평가 답변"으로 반영 계획을 남겨도 됩니다.

관점보는 것
문제 정의·기여연구질문이 분명한가, 기여점이 새로운가
방법 타당성기법 선택(또는 연구설계·측정)이 질문에 맞는가
실험·근거결과가 충분하고 재현 가능한가, 해석이 타당한가, 대안 설명을 배제했는가
글쓰기·완성도구성·그림·표·문장
기록 충실도연구노트에 매주 진행이 남아 있는가, 피드백에 답했는가

회차마다 중심이 다릅니다. 1~2회차는 문제 정의, 3회차는 방법·설계, 4회차는 결과, 5~6회차는 글쓰기를 주로 봅니다.

발표 전 체크리스트

  • ☐ 슬라이드 5장 이내, 5분 안에 끝나는지 한 번 돌려봤다
  • ☐ 연구질문 한 줄과 다음 할 일·막힌 점이 들어 있다
  • ☐ 수치가 있는 장에는 설정(데이터 크기·모델·시드·반복 수 / 표본 수·척도·분석 모형)이 적혀 있다
  • ☐ 지난 회차 피드백을 어떻게 반영했는지 한 줄 있다
  • ☐ (권장) 연구노트에 해당 단계 정리를 갱신하고 이번 회차 기록을 올려두었다
