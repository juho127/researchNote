연구노트 시작 안내

가입 → AI 도구 연결 → 기록. 3단계면 끝납니다.

여러분이 Claude Code 같은 AI 도구로 연구하면, 그 도구가 진행 상황을 연구노트에 자동으로 기록합니다. 교수는 그 기록을 보고 피드백을 남기고, 발표·보고서는 이 기록을 바탕으로 만듭니다. 아래 3단계만 하면 됩니다.

1단계. 계정(토큰) 신청

  1. 상단 토큰 신청 (/#/apply)
  2. 이름, 이메일, 소속을 입력합니다.
  • 대학원 수업 수강생 → 2026년2학기 대학원수업
  • 캡스톤 팀 → 2026년 2학기 캡스톤프로젝트
  • 메모란에 학번-학과-이름을 적어주면 승인이 빠릅니다.
  1. 신청 직후 화면에 수령 코드(clm_로 시작)가 한 번 나옵니다. 반드시 복사해서 보관하세요. 다시 볼 수 없습니다.
  2. 교수가 승인하면 /#/claim/수령코드 페이지에서 토큰(rn_로 시작)을 딱 한 번 받습니다.
⚠️ 가장 흔한 실수: 수령 코드(clm_…)와 토큰(rn_…)은 다릅니다. AI 도구 설정에 넣는 것은 rn_로 시작하는 토큰입니다.
토큰을 잃어버렸다면 새로 신청하지 마세요(같은 이메일은 중복으로 거부됩니다). /#/reissue에서 신청할 때 쓴 이름 + 이메일을 입력하면 즉시 재발급됩니다.

2단계. AI 도구에 연결

가장 쉬운 방법은 AI에게 시키는 것입니다. Claude Code(또는 Cursor, Codex CLI, Gemini CLI)를 열고 이렇게 말하세요.

https://research-note.juho-2b6.workers.dev/connect 읽고 연구노트에 연결해줘.
내 토큰은 rn_... 이야.

AI가 그 문서를 읽고 MCP 등록, 사용 지침 저장, 연결 검증까지 알아서 합니다.

직접 하고 싶으면 Claude Code 기준 한 줄입니다.

claude mcp add --scope user --transport http research-note https://research-note.juho-2b6.workers.dev/mcp --header "Authorization: Bearer rn_여기에토큰"

연결 확인: AI에게 "연구노트 whoami 해줘" 라고 하면 이름과 소속이 나옵니다.

3단계. 쓰는 법

연구 폴더에서 AI와 작업한 뒤, 그냥 말로 시키면 됩니다.

하고 싶은 것이렇게 말하세요
프로젝트 만들기"연구노트에 내 논문 프로젝트 등록해줘"
오늘 진행 기록"오늘 한 일 연구노트에 기록해줘"
단계 정리 갱신"지금까지 결론 정리해서 기획 단계에 반영해줘"
다음 할 일 등록"다음 할 일 연구노트 할일로 등록해줘"
공지 확인"연구노트 공지 읽어줘"
팀 현황 보기"팀 피드 보여줘"
교수 검토 요청"이 기록 검토 요청으로 올려줘"
발표 자료 초안"지난 2주 기록으로 보고서 뽑아줘"

논문 트랙 단계: 기획 → 리서치 → 관련기법 → 실험결과 → 논문작성 → 검토·투고
캡스톤 트랙 단계: 주제·문제 발견 → 시장·사업모델 → MVP 빌드·배포 → 피드백·개선 → 사업성·최종보고 → 최종 발표

기록 원칙

  • 매주 최소 1건은 남기세요. 기록 충실도가 평가에 들어갑니다.
  • 한 기록에 한 주제. 실험이 두 개면 기록도 두 개입니다.
  • 잘 안 된 실험도 기록하세요. 원인 가설까지 적으면 그게 곧 논문의 한 절이 됩니다.
  • 수치는 설정값(데이터 크기, 모델, 시드, 반복 수)과 함께 적습니다.
  • AI가 지어낸 내용이 들어가지 않도록, 기록 올리기 전에 한 번 읽어보세요.
